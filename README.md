# Nuvora apps

Downloads for Nuvora desktop apps. Every build is signed and notarized. Apple Silicon only.

| App | What it does | Requires | Download |
|---|---|---|---|
| **Forge** | Session manager for Claude Code | macOS 14+ | [Releases tagged `forge-v*`](https://github.com/nuvoralabs/nuvora-apps/releases?q=forge-v) |
| **Weave** | On-device dictation and meeting notes | macOS 26+ | [Releases tagged `weave-v*`](https://github.com/nuvoralabs/nuvora-apps/releases?q=weave-v) |

Open the DMG and drag the app to Applications.
