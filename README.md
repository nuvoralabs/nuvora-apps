# Nuvora apps

Downloads for Nuvora desktop apps. Every macOS build is signed and notarized.

| App | What it does | Requires | Download |
|---|---|---|---|
| **Forge** | Session manager for Claude Code | macOS 14+, Apple Silicon | [Releases tagged `forge-v*`](https://github.com/nuvoralabs/nuvora-apps/releases?q=forge-v) |
| **Weave** | On-device dictation and meeting notes | macOS 26+, Apple Silicon | [Releases tagged `weave-v*`](https://github.com/nuvoralabs/nuvora-apps/releases?q=weave-v) |
| **StackHelm** | Supervision of local dev services | macOS 11+ (Universal), Linux | [Releases tagged `stackhelm-v*`](https://github.com/nuvoralabs/nuvora-apps/releases?q=stackhelm-v) |

On macOS, open the DMG and drag the app to Applications.
